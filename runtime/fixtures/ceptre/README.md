# runtime/fixtures/ceptre — fixtures compiled from the Ceptre love triangle

`live_love_triangle.wire`, `live_love_triangle.txt` and
`proj_love_triangle.txt` are generated by metispy's
`tools/gen_smoke_fixtures.py` (through `tools/gen_live_goldens.py`) from
`corpus/ceptre/love_triangle.llp`, a port of the Ceptre tutorial's love
triangle (interactive-lp). The ctest cases `abi_smoke`, `live_love_triangle`
and `project_love_triangle` read them.
